## 🌟 Major Highlights

`doubao-ime-linux` 0.8.0 marks a milestone leap from an early experimental prototype to a **modern, production-grade hybrid input method architecture** for Linux desktops. It brings deep integration with ByteDance's official Doubao 0.9.2.7 engine, sub-10ms local neural network prediction, zero-Wine streaming voice input with cloud LLM text organization, and massive memory slimming.

```text
[Keyboard Input Channel]
Keys → Fcitx 5 (Native Addon) → Unix Domain Socket (10ms) → Single Wine Container
     → Doubao 0.9.2.7 Engine (135MB Multi-tier Trie + Local Quantized ONNX Neural Network)
     + Live Cloud Candidate Stream (QUIC / HTTPS to ime-gw3.oceancloudapi.com)

[Voice & Smart Organization Channel (Zero-Wine)]
Voice (Right Ctrl / Alt) → PipeWire → fcitx5-vinput (Native Addon, 20MB RAM)
     → Pure Python Official Streaming ASR (wss://frontier-audio-ime-ws.doubao.com)
     → Local Loopback (:19283) Doubao LLM Text Organization (https://ime.doubao.com/api/v2/ai/text_organization)
     → Direct Commit (Auto Punctuation, Disfluency Removal, Semantic Correction)
```

## 🚀 Key Improvements & Architecture Upgrades

### 1. Hybrid Dual-Engine Architecture (双核混合驱动)
- **Local Neural Network Inference**: Incorporates Microsoft `onnxruntime.dll` with official quantized neural models to perform real-time local semantic prediction and context re-ranking directly inside the engine, achieving near-perfect long-sentence accuracy with 10ms local latency.
- **Edge Cloud Candidate Streaming**: Native integration with `enableCloudCandidate: true`, dispatching asynchronous QUIC / HTTPS queries to ByteDance Ocean Cloud (`ime-gw3.oceancloudapi.com`), continuously enriching candidates with trending phrases and buzzwords.
- **Zero-Wine Native Voice Input**: Completely deprecates the cumbersome, legacy Wine voice/organize prefix. Replaced by a native, ultra-lightweight architecture using `fcitx5-vinput` (20MB RSS) and pure Python reverse-engineered official streaming endpoints (`wss://frontier-audio-ime-ws.doubao.com`).
- **Official Doubao LLM Text Organization**: Exposes an OpenAI-compatible endpoint at `http://127.0.0.1:19283/v1` connecting to ByteDance's live `/api/v2/ai/text_organization`. Voice dictation automatically strips spoken disfluencies (e.g. "嗯、啊、那个"), corrects homophone errors, adds proper Chinese punctuation, and commits polished text directly to the screen.

### 2. Extreme Slimming & Resource Optimization (深度瘦身)
- **Eliminated Duplicate Wine Container**: Purged the redundant `doubao-imeservice.service` that ran a parallel 1.8GB Wine prefix and a duplicate Xvfb display. Unified all keyboard tasks into a single managed prefix.
- **Memory Dropped by >40%**: Active Doubao stack RSS decreased from ~900MB to ~440MB.
- **Zero-Leak Isolation**: Seamlessly integrates with `fcitx5-schemes`. Switching to lightweight schemes (e.g. WowType or Native Pinyin) terminates all Wine and Xvfb processes cleanly with 0 zombie processes, dropping background footprint to just 47MB.
- **Disk Cleaned**: Cleaned 600MB+ of legacy package extractions, stale caches, and hot logs.

### 3. Industrial-Grade Reliability, Self-Healing Boot & Keystroke Storm Fix (按键对称状态机与开机自愈)
- **Non-blocking Key Release**: Completely removed synchronous blocking RPCs on ordinary key release events (`isRelease()`). Regular key releases are immediately consumed on the client side at 0 microseconds, strictly preventing RPC queue buildup (>250ms) during fast typing.
- **Key Symmetrical State Machine**: Tracks physical key states symmetrically, preventing lost key-up events from triggering infinite Backspace repeats or auto-deletion storms.
- **2.0s Win32 Fast Boot & On-Demand Self-Healing**: Replaces external `wine reg add` subprocesses with direct Win32 `RegSetValueExW` calls inside `keyboard-host.exe`, cutting cold startup time to **2.0s** and reducing peak startup memory from `1.2GB` to **`400MB`**. Furthermore, `doubaoime.so` includes `ensureBackendStarted()` on-demand self-healing that automatically starts `doubao-keyboard.service` if the socket is absent.
- **Shift Phase-Inversion Elimination**: Enforces `useShift: false`, `enableEnglishMode: false`, and `defaultChinese: true` in `ImeService.exe` and stops forwarding bare `Shift`/`CapsLock` mode toggles to the Wine engine, ensuring Fcitx 5 is the single source of truth for Chinese/English state.
- **Xvfb Multi-head Conflict Avoidance**: Dynamically selects isolated X display numbers (95-120), preventing accidental collision with Xwayland `:0`.
