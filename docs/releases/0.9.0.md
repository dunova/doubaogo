## 🌟 Major Highlights

`doubaogo` 0.9.0 is a flagship milestone release, officially rebranding from `doubao-ime-linux` to **doubaogo** and establishing a modern standard for Linux desktop input methods. 

This release introduces native zero-Wine inline streaming voice dictation with ByteDance Doubao LLM smart text organization, alongside a heavily slimmed hybrid keyboard typing engine powered by official Doubao 0.9.2.7 runtime with local ONNX neural context prediction.

---

## 🚀 Key Improvements & Architecture Upgrades

### 1. Zero-Wine Native Streaming Inline Voice Dictation
- **Native ClientPreedit Inline Typing**: Real-time streaming speech recognition injected directly at the active application cursor (`zwp_text_input_v3` / X11 IM) with automatic multi-line text wrapping within host applications (Omawrite, VS Code, Chrome, Telegram).
- **Zero Full-Screen Bar Interruption**: Completely eliminated the legacy 3840px full-screen floating candidate bar and truncated display (`MaxStreamingDisplayWidth`).
- **Seamless Zero-Menu Direct Commit**: Abolished manual 1/2 candidate selection dialogs upon speech completion; ByteDance Doubao LLM polished text automatically commits to the focused application in ~300ms.
- **Pure Native Audio Capture & Cloud Polishing**: High-speed WebSocket streaming ASR directly via PipeWire / ALSA (20MB RSS footprint) paired with official Doubao LLM text organization for automatic disfluency removal, spoken filler word stripping, and punctuation restoration.
- **Zero Clipboard Pollution**: Completely eradicated fallback reads to the primary clipboard during speech recognition.

### 2. Hybrid Dual-Engine Keyboard Architecture with Local Neural Inference
- **Official Doubao 0.9.2.7 Runtime**: Integrates ByteDance's production-grade input engine running within a lightweight, slimmed single-Wine micro-container.
- **Local ONNX Neural Inference**: Microsoft `onnxruntime.dll` and official quantized neural models calculate semantic context and perform candidate re-ranking locally in ~10ms for exceptional long-sentence accuracy.
- **135MB Multi-tier Trie Lexicon**: Comprehensive built-in binary trie dictionary paired with personalized bigram learning and custom phrase expansion.
- **Millisecond Edge Cloud Candidates**: Native integration with `enableCloudCandidate: true`, dispatching high-speed QUIC / HTTPS queries to ByteDance Ocean Cloud (`ime-gw3.oceancloudapi.com`) for live trending phrases.

### 3. Industrial-Grade Reliability & Fast Boot
- **Key Symmetrical State Machine**: Tracks physical key states symmetrically, completely preventing lost key-up events from triggering infinite Backspace repeats or auto-deletion storms.
- **0-Microsecond Key Release**: Non-blocking asynchronous handling for normal key-up events, guaranteeing sub-10ms latency without input method freezing or timeout lag.
- **2.0s Win32 Fast Cold Boot**: In-process Win32 `RegSetValueExW` registry initialization cuts cold boot to 2.0s and slashes startup peak memory to ~400MB.
- **Zero Shift Phase Inversion**: Fcitx 5 exclusively manages Chinese/English mode toggling, eliminating 180° state desync between Fcitx 5 and the Wine engine.
- **Zero-Leak Scheme Switching**: Full compatibility with `fcitx5-schemes`, cleanly reclaiming all Wine and Xvfb processes when switching to lightweight input methods.
